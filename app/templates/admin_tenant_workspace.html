Full Tenant Backup & Restore Export one full backup file or import one backup file into this tenant. ▾

Full Tenant Backup & Restore

Export creates one Unboks backup file containing the tenant runtime folder, dashboard credentials, knowledge files, runtime databases, prompt/SOT data, channel metadata, notes, and Nr3 state. Import replaces this tenant with the backup contents while preserving the selected tenant's slug, container name, and route.

Export full tenant backup

Downloads one .unboksbackup file. Keep that file; do not import extracted folder contents.

Import full tenant backup

Choose the one exported backup file and import it. Nr3 creates a rollback first, removes this tenant's old data, restores the backup, and rewrites only the target-specific slug/container identity needed to keep this tenant working.
